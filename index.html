Security & Integrity Architecture

Built from the ground up to prevent OWASP Top 10 banking vulnerabilities

Pessimistic Concurrency Locking

Enforces PESSIMISTIC_WRITE row locking in deterministic ID order. Completely eliminates race conditions, double-spending, and transaction deadlocks under simultaneous traffic.

Immutable Audit Trail

Every transaction, blocked action, and failed attempt is recorded irrevocably. Actor identity is extracted strictly from the cryptographic SecurityContext, never trusting frontend parameters.

Role-Based Access & IDOR Defense

Spring Security 6 with Method-level @PreAuthorize prevents unauthorized access. User profile and balance endpoints bind directly to the authenticated session context.
